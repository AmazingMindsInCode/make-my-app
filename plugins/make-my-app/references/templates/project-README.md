## 怎么启动（双击就能用）

1. 双击项目里的 **start.bat**
2. 第一次启动会自动组装（等几分钟，以后就快了）
3. 浏览器会自动打开 `http://localhost:8080`，就是它了

> 用完直接关掉黑窗口就是关机。数据都记在 MySQL 数据库里，不会丢。

## 想改点什么？

直接打开 ZCode，在这个项目里说人话就行，比如：
- "把『记一笔』按钮改成绿色"
- "账单列表加上按类别筛选"
- "我想给家里人也能用（局域网）"

## 数据存在哪

- 存在**文件名**：`application-local.yml`（不在存档里，换电脑要重设）
- 数据库在本机 MySQL，库名 `myapp`

## 遇到问题

| 现象 | 先试这个 |
|---|---|
| 双击 start.bat 一闪而过 | 右键"编辑"看报错；或问 AI"start.bat 启动失败" |
| 页面打不开 | 看黑窗口是否还开着；重启 start.bat |
| 提示数据库连不上 | services.msc 里启动 MySQL80，再重启 start.bat |
