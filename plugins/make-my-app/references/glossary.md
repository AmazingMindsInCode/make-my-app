# 大白话术语表

原则：**先比喻，后术语，每次只教一个新词**。向用户解释时从本表取说法；表里没有的词，先想一个生活比喻再解释。绝不连用两个未解释的术语。

## 沟通规范（全插件统一，每个技能都必须遵守）

1. **与用户的对话只聚焦四类内容**：需求（要做什么）、功能描述（做成了什么样）、业务场景（谁在什么情况下用）、流程节点与行为（现在到哪一步、谁要做什么）。
2. **不主动展示**：代码片段、框架名、依赖版本、报错堆栈、目录结构。用户主动问技术问题时，先用本表比喻解释概念，再给最少量的必要细节。
3. **术语先解释后使用**：对话中第一次出现的技术词，必须紧跟一个括号比喻（如"接口（就是页面和后台之间递单子的窗口）"），此后可直接使用。
4. **一次一个新词**：一句话里最多出现一个未解释过的术语，否则改写。
5. **用用户的业务词**：用户说"工单"就全程"工单"，不擅自改成"订单"。
6. 术语表是活的：对话中新解释过的词，补充进本表（比喻 + 一句话 + 跟当前项目的关系）。

## 基础概念

- **软件 / 程序 / 应用**：让电脑帮你干具体活的东西。你要做的"记账本""小网站"都是一个软件。
- **代码**：写给电脑看的工作指令，就像菜谱之于厨师。
- **前端**：软件里"看得见摸得着"的部分——页面、按钮、输入框。好比餐厅的用餐区。
- **后端**：看不见的部分——存数据、算账、管权限。好比餐厅的后厨。
- **网页 / 页面**：在浏览器里看到的一屏内容。
- **浏览器**：Chrome、Edge 这类用来看网页的软件。

## 数据相关

- **数据库**：一个特别靠谱的电子账本，记进去的东西断电也不丢。我们用的是 MySQL。
- **表**：账本里的一页，一格一格那种表格。比如"账单表"。
- **字段**：表格的一列。比如账单表有"金额""日期""备注"三列。
- **记录**：表格的一行，就是"一笔账"。
- **SQL**：跟数据库说话用的语言，比如"把这个月的账加一下"。

## 网络相关

- **接口（API）**：前端和后端之间传递东西的窗口，像银行柜台的取号口——递进去请求，递出来结果。
- **请求 / 响应**：你递进窗口的单子 / 窗口递出来的回执。
- **JSON**：一种全世界通用的"标准便签"格式，窗口两边递东西都用它。
- **端口**：电脑这栋大楼的门牌号。我们的软件住 8080 号房间，MySQL 住 3306 号。
- **localhost**：电脑叫自己的名字。"localhost:8080"= 本电脑 8080 房间。
- **IP 地址**：电脑在网络里的门牌号，像"192.168.1.5"。
- **域名**：给 IP 起的好记别名，像"taobao.com"。
- **防火墙 / 安全组**：门卫。外人来串门要先在门卫那登记放行，否则进不来。

## 制作过程相关

- **JDK**：做 Java 软件的全套工具箱。我们用 17 号版本。
- **Maven（mvnw）**：自动帮你搬原料的采购员，需要的零件它自己去下载。项目里自带，不用你装。
- **Node.js / npm**：前端界的工具箱和采购员。只在改页面时才需要。
- **构建 / 打包**：把一堆零件组装成一个能双击运行的成品。成品是一个叫 `app.jar` 的文件。
- **jar 文件**：打包好的整个软件，一个文件装全部。
- **依赖**：软件要用的别人做好的零件，采购员会自动下载。
- **存档点（commit）**：游戏存档——把当前进度拍快照，搞砸了随时读档回到这里。
- **git**：管理存档点的时光机。插件会自动操作，你只管说"存个档""回到上个存档"。
- **验收**：请一位没参与开发的"独立考官"按需求清单逐条检查，全过才算完成。

## 上线相关

- **部署 / 上线**：让软件从"只有我自己能用"变成"别人也能用"，像店铺开门营业。
- **本机运行（L1）**：软件只在自己电脑上跑，自己用。
- **局域网（L2）**：同一个 WiFi 里的其他手机电脑也能访问，像只对家人开门。
- **公网上线（L3）**：全世界都能访问，像临街开店。需要租一台云上的电脑（云服务器）。
- **云服务器**：租来的、24 小时开机的远程电脑，阿里云/腾讯云都能租。
- **nginx**：公网门口的接待员，负责把访客领到你的软件面前（L3 可选）。
- **HTTPS**：加密通道，网址带锁标。上公网收用户信息时建议配。

## 与 AI 协作相关

- **需求单**：我们聊天后整理的"你要什么"清单，编号 R1、R2…，是验收的唯一依据。
- **方案卡**：同一个需求的 2-3 种做法说明，像点菜单，选一张就开工。
- **功能（task）**：需求拆成的一件件小活，编号 T1、T2…，做一件验一件。
- **进度文件（progress.json）**：插件记的账本，你在哪一步、做了什么、存了哪些档，都在里面，换会话也不丢。
- **遗留缺陷**：明知道但暂时不修的小毛病，登记在案，避免反复发现反复报告。
