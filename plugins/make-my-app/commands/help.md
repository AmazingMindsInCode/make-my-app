# 「我要做软件」使用指南

你只需要记住一件事：**把你想做的东西用大白话说出来**，剩下的交给我们。

## 四个常用口令

| 口令 | 什么时候用 |
|---|---|
| `/start 我想做一个家庭记账本` | 从零开始做一个新软件 |
| `/continue` | 接着上次没做完的继续 |
| `/status` | 看看现在做到哪一步了 |
| `/ask 下一步干嘛？` | 迷茫了，问教练（也可以问任何术语的意思） |
| `/export` | 把踩过的坑和建议打包成报告，发给开发团队让软件更好用 |

也可以直接说话，不用口令："我想做个东西记录我养的猫""继续那个项目""存个档"。

## 我们会带你走完整条路

1. 💬 **聊清楚**你想做什么（一次只问一个问题）——聊的过程中给你**看得见的材料**：业务流程图、使用剧本、第一屏画面草图（双击就能打开的网页），反复改到你说"就是它"才开工
2. 🃏 给你 2-3 张**做法卡片**挑一个（每张都明说好处和妥协）
3. 🔧 你的电脑缺什么工具，**手把手**带你装好
4. 🧱 搭骨架 → **一个功能一个功能做**，每个做完都：
   - 请独立测试员按验收标准逐条测
   - 跑给你亲眼看到
   - 自动存档（随时能回到任何一个存档点）
5. ✅ 请没参与开发的**独立考官**整体验收
6. 🚀 **三级渐进上线**：自己用 → 同 WiFi 的家人用 → 全世界能用（每一级停下来都算成功）
7. 💾 全程自动存档，换会话、隔几天回来都不丢进度
8. 🧠 需要时自动调用专项工具箱（页面设计、浏览器验证、测试方法论、文案润色）——征得你同意后安装，说"更新组件"随时升级

## 三个承诺

- **不说黑话**：必须用技术词时会先给你打个比方
- **不糊弄**：说"做完了"就一定有跑给你看的证据；修好了必定请你亲手再试
- **不硬闯**：花钱的事永远你说了算；装软件你点头后我可以代劳（密码除外——密码永远你自己输）

遇到不懂的词，随时 `/ask XX是什么意思`。
