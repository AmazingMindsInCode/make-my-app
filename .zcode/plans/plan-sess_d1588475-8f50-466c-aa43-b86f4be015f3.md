## 设计灵魂：从 508 个历史会话提炼的 10 条护栏（写入各 skill 的反模式清单）

1. **唯一入口**：新用户不选 skill，只说"我想做XX"或敲 `/start`；状态机路由，不看术语看工件
2. **一次一问**：选择题优先 + 推荐答案，未答按推荐推进并标注（你的实测偏好）
3. **机读真相源**：进度存 `.make-my-app/progress.json`，绝不靠会话记忆判断进度
4. **验证闭环**：AI 说"修好了"必须复现验证（浏览器/命令行）才算数——历史最大痛点
5. **Edit 前必重新 Read**：防 IDE 并发修改（历史 55 次报错）
6. **环境防呆前置**：开工先体检，纯英文路径强制检查（历史：中文路径毁 POM）
7. **不过度设计**：能配置文件解决的不建表
8. **断点续作**：任何新会话 `/continue` 精确恢复
9. **术语翻译层**：先比喻后术语（"数据库=电子账本"），每次只教一个新词
10. **部署分级可停**：做不动就停在前一级，软件照样能用

## 核心机制

**状态机**（mma-guide 按工件+progress.json 双重判定，非法转换阻止）：
`env-check → requirement → solution → env-setup(按需) → scaffold → build ⇄ verify → ship-L1 → ship-L2 → ship-L3 → done`，任意状态可 savepoint；`/status` 输出大白话看板（"第3步共7步：正在搭你的软件骨架"）。

**progress.json schema**：`{app名, stage, stageHistory[], tasks[{id,title,status}], decisions[], saves[{msg,time}], MySQL连接信息位置(不含密码), updatedAt}`——密码只进 `application-local.yml`（.gitignore，历史规范"口令不入仓库"）。

**黄金路径关键决策**（golden-path.md，替新手全部选好）：
- 项目路径强制纯英文（体检项）；JDK17 Temurin/Dragonwell（国内镜像直链）；**Maven 不装**——脚手架带 mvnw + 项目内 aliyun-settings.xml，start.bat 里 `mvnw.cmd -s .mvn\aliyun-settings.xml spring-boot:run`；Node LTS（华为镜像）只在改前端时需要
- MySQL 8 向导：Server only 安装→root 密码→建库 utf8mb4→连接测试，附排错表（3306 占用/服务未启动/密码错）
- 前端构建产物打进 Spring Boot static → **单个 jar 双击 start.bat 即用**（对新手的最小可交付物）
- git 完全隐藏：自动 init/add/commit，"存档点"隐喻，status 显示存档列表；已存在 .git 则尊重只追加

**mma-ship 三级向导**（每级=确认门+分步指令+验证+停在这里也 OK）：
- L1 本机：打 jar + start.bat + localhost:8080 验证
- L2 局域网：查本机 IP+防火墙放行+同事手机访问验证
- L3 公网：轻量云服务器选购建议→安全组→JDK→上传 jar→后台运行（nssm/systemd）→可选 nginx+域名

## 实施步骤

1. **骨架**：建目录树 + plugin.json（name=make-my-app, version 0.1.0, 中英 description, 声明 skills/commands/agents/hooks）+ marketplace.json（本地市场条目）
2. **references 先行**：state-machine / golden-path / pitfalls（把调研报告的教训逐条转录入：Maven settings 坑、JDK 错位、中文路径、Git Bash 编码、并发编辑、视觉误判用程序化测量兜底等）/ glossary / templates
3. **8 个 skills**：全部自包含，frontmatter description 中文 ≤500 字（上限 1024），正文含流程+护栏+引用 references；mma-guide 启动协议仿 team-orchestrator（读 progress→校验工件→恢复/重做判定→绝不重做已完成）
4. **4 个 commands**：frontmatter 用 `skills:` 预载 mma-guide；$ARGUMENTS 透传
5. **agent + hooks**：rookie-reviewer（fresh-eyes 独立验收，不传开发历史，按需求单逐条 pass/fail，只读）；SessionStart hook 输出 additionalContext 提醒"你有未完成的《XX》，/continue 继续"
6. **校验**：结构自查（清单齐全、frontmatter 长度、路径不越界）+ 可选 `zcode plugins validate`
7. **安装交接**：按 plugin-creator 流出中文交接说明（UI：插件市场→添加→粘贴本地市场根目录→安装→启用），不代装不谎报
8. **冒烟演练**：安装后新会话跑 `/start 我想做一个家庭记账本`，走通 requirement→solution 确认门，验证状态机落盘与断点恢复

## 验收标准

- plugin.json 合法、组件文件齐全、目录名=slug、frontmatter 全部 ≤1024 字符
- 全部 skill 自包含：在一台只有 ZCode 裸机的电脑上可用（不引用 ~/.agents 下任何 skill）
- 状态机/断点恢复/验证闭环/密码不落仓库 四机制在 SKILL.md 中有明确可执行规则
- 冒烟演练通过（需求→方案→progress.json 正确落盘，/continue 可恢复）
- 交接文档含：本地安装步骤 + 未来发布到 git 市场的说明
